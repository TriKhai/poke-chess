POKE AUTO CHESS ME v1.1.1 - RARITY CARDS / TEAM INSPECTOR
=========================================================

TYPE ICONS
- Text chips in shop/selected-Pokemon and Collection info were replaced with
  icons already bundled under res/type.
- English filenames are retained internally so resource loading is unchanged.

RARITY SHOP CARDS
- Exact colors copied from app.zip public/src/style/colors.css.
- Card body uses a darkened rarity color for portrait readability; the top edge
  uses the exact source color. Selection keeps the existing yellow outline.
- Each card displays one or two Pokemon type icons at its right edge.

COMBAT TEAM INSPECTOR
- FIRE pauses combat and opens a full-screen roster overlay.
- Two tabs: ĐỘI MÌNH [1] and ĐỘI ĐỊCH [3].
- Each team supports up to nine Pokemon in a 3-column x 3-row grid.
- Arrow keys select a Pokemon; FIRE opens its live detail page.
- Detail page includes HP/PP, combat stats, skill, description, shield,
  crit/dodge and all simultaneous supported status icons/names.
- FIRE/0 returns from details; 0/right softkey closes the roster.
- Outside the inspector, * cycles x1/x2/x4 and 9 skips the battle.
