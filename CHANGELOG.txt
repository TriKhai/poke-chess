Compatibility
- No floating point, collections, timers, alpha APIs or MIDP 2.1-only calls added.
- New runtime state uses fixed-size primitive arrays to remain CLDC 1.0 friendly.
- Original Ant + preverify build flow and build-poke.bat are unchanged.
- Runtime animation assets now live under res/raw and res/fx; the 440MB source assets are not
  copied into the JAR and do not need to be unpacked into src.

Validation
- All Java source files compile together against a minimal MIDP/CLDC API surface.
- A real device/emulator JAR must still be produced by build-poke.bat so Java ME
  SDK preverify can create CLDC-verifiable class files.
