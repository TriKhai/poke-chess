# Poke Auto Chess ME 1.4.1

Post-battle visual hotfix for the 1.4.0 stable baseline.

- Clears damage text, projectiles, skill effects and persistent board effects
  immediately when combat simulation ends.
- Clears stale hit, cast, attack and movement animation state.
- Result-screen idle motion uses the visual clock, which continues after the
  deterministic battle tick stops.
- No gameplay or save-schema changes.
