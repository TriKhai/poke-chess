POKE AUTO CHESS ME v1.1.6a
==========================

- Root cause: glyph index zero is SPACE with height 1px.
- v1.1.6 used that glyph as Art.fh, collapsing all vertically stacked UI text.
- PixelFont now scans every glyph and returns the maximum glyph height.
- Art uses that measured height as the global line height.
- Bitmap font and optimized item assets are otherwise unchanged.
- MIDlet-Vendor remains KhaiLy.
- Numeric build.xml/JAD/manifest version remains 1.1.6.
